# Internationalization - Meteo360

Meteo360 uses Transloco with the MessageFormat plugin. The current MVP is French-only in the UI, but the translation setup already follows a maintainable pattern that keeps all user-facing strings centralized.

## Dependencies

```json
{
  "@jsverse/transloco": "^8.3.0",
  "@jsverse/transloco-messageformat": "^8.3.0"
}
```

## Configuration Location

The core i18n configuration lives in:

```text
frontend/src/app/app.config.ts
```

Current loader pattern:

```typescript
@Injectable({ providedIn: 'root' })
export class TranslocoInlineLoader implements TranslocoLoader {
  getTranslation(): Observable<Translation> {
    return of(frTranslations);
  }
}
```

Relevant provider excerpt from `app.config.ts`:

```typescript
import { LOCALE_ID } from '@angular/core';
import { environment } from '../environments/environment';

provideTransloco({
  config: {
    availableLangs: ['fr'],
    defaultLang: 'fr',
    reRenderOnLangChange: true,
    prodMode: environment.production,
  },
  loader: TranslocoInlineLoader,
}),
provideTranslocoMessageformat(),
{ provide: LOCALE_ID, useValue: 'fr-FR' }
```

## Translation Source

Translations currently live in:

```text
frontend/src/app/i18n/fr.ts
```

The project does not use JSON translation assets for the MVP.

## Usage Rules

- all user-facing Angular text must use Transloco keys
- standalone components that render translated text must import `TranslocoModule`
- do not hardcode visible UI strings in templates or components
- keep translation keys grouped by domain rather than scattering ad hoc strings

Template example:

```html
{{ 'weather.loading_forecast' | transloco }}
```

## Testing

Tests should use the shared helper in:

```text
frontend/src/app/testing/transloco-testing.module.ts
```

Rules:

- import `getTranslocoTestingModule()` instead of rebuilding Transloco test config inline
- keep test expectations aligned with the current translation keys
- keep translation fixtures synchronized with `frontend/src/app/i18n/fr.ts`

## Current Scope And Future Changes

The current UI is configured for French only:

- `availableLangs: ['fr']`
- `defaultLang: 'fr'`
- `LOCALE_ID: 'fr-FR'`

If additional languages are introduced later, update the Transloco config, translation assets, tests, and documentation in the same change set.
