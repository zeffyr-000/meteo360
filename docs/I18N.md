# Internationalisation - Meteo360

Meteo360 utilise Transloco et Transloco MessageFormat sur le meme modele que `suiviseries`.

## Dependances

```json
{
  "@jsverse/transloco": "^8.3.0",
  "@jsverse/transloco-messageformat": "^8.3.0"
}
```

## Configuration

La configuration vit dans:

```text
frontend/src/app/app.config.ts
```

Pattern attendu:

```typescript
@Injectable({ providedIn: "root" })
export class TranslocoInlineLoader implements TranslocoLoader {
  getTranslation(): Observable<Translation> {
    return of(frTranslations);
  }
}
```

Providers:

```typescript
import { environment } from "../environments/environment";

(provideTransloco({
  config: {
    availableLangs: ["fr"],
    defaultLang: "fr",
    reRenderOnLangChange: true,
    prodMode: environment.production,
  },
  loader: TranslocoInlineLoader,
}),
  provideTranslocoMessageformat());
```

## Fichier De Traduction

Les traductions vivent dans:

```text
frontend/src/app/i18n/fr.ts
```

Le fichier exporte:

```typescript
export const frTranslations = {
  app: {
    title: "Meteo360",
  },
};
```

Ne pas ajouter de fichiers JSON dans `assets/i18n` sans demande explicite.

## Usage Dans Les Templates

Importer `TranslocoModule` dans le composant standalone, puis utiliser le pipe:

```html
<h1>{{ 'app.dashboard' | transloco }}</h1>
<button [matTooltip]="'app.refresh' | transloco"></button>
```

## Usage Dans TypeScript

Pour les messages calcules ou erreurs:

```typescript
private readonly translocoService = inject(TranslocoService);

this.error.set(this.translocoService.translate('search.no_results'));
```

## Tests

Utiliser le helper central:

```text
frontend/src/app/testing/transloco-testing.module.ts
```

Exemple:

```typescript
imports: [App, getTranslocoTestingModule()];
```

Ne pas dupliquer la configuration `TranslocoTestingModule.forRoot()` dans chaque spec.

## Conventions De Cles

Regrouper les cles par domaine:

```text
app.*
search.*
weather.*
places.*
hourly.*
daily.*
```

Recommandations:

- utiliser des noms descriptifs
- eviter les cles basees sur le texte exact
- garder les erreurs utilisateur dans Transloco
- garder les erreurs techniques backend dans l'API PHP

## MessageFormat

MessageFormat est disponible pour les futurs pluriels:

```typescript
forecast_days: "{count, plural, =0 {Aucun jour} one {# jour} other {# jours}}";
```

Dans le template:

```html
{{ 'weather.forecast_days' | transloco: { count: days.length } }}
```

## Checklist I18n

- Tout texte utilisateur Angular utilise Transloco.
- Les tooltips et aria-labels sont traduits.
- Les messages d'erreur UI sont traduits.
- Les tests importent `getTranslocoTestingModule()`.
- Les cles inutilisees sont supprimees lors des refactorings.
